# Variable

### Variable Name
- Must start with a letter or underscore '_'
- Cannot start with a number
- Can only contain alpha-numberic characters & "_"
- Case sensitive 
- Cannot be any of the python keyword

### Multiwords Variable Name
#### Camel Case
```
myVariableName = "John"
```

#### Pascal Case
```
MyVariableName = "John"
```

#### Snake Case
```
my_variable_name = "John"
```

### Many values to Multiple variables
```
x, y, z = "Orange", "Apple", "Banana"
print(x)
print(y)
print(z)
```

### One to Multiple variable
```
x=y=z = "Orange"
print(x)
print(y)
print(z)
```

`Note`  
In python, variables do not need to be declared with any particular type.  
It can change type after they have been set.
